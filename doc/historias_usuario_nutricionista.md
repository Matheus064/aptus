# Histórias de Usuário — Nutricionista — Aptus

## 1. Objetivo

Descrever as principais necessidades do usuário com perfil de **Nutricionista** no sistema Aptus, utilizando o formato de histórias de usuário.

## 2. Histórias de Usuário

### HU-NUT-01 — Acessar o sistema
**Como** nutricionista,  
**quero** realizar login no sistema,  
**para** acessar minhas funcionalidades e informações de trabalho.

**Critérios de aceitação:**
- O nutricionista deve informar suas credenciais.
- O sistema deve validar as credenciais.
- Após o login, o nutricionista deve ser direcionado à área correspondente ao seu perfil.

### HU-NUT-02 — Gerenciar perfil profissional
**Como** nutricionista,  
**quero** visualizar e editar meus dados profissionais,  
**para** manter minhas informações atualizadas.

**Critérios de aceitação:**
- O nutricionista deve conseguir visualizar seus dados.
- O nutricionista deve conseguir editar os campos permitidos.
- O sistema deve validar os dados antes de salvá-los.

### HU-NUT-03 — Cadastrar paciente
**Como** nutricionista,  
**quero** cadastrar um paciente,  
**para** iniciar e organizar seu acompanhamento nutricional.

**Critérios de aceitação:**
- O nutricionista deve conseguir informar os dados necessários do paciente.
- O sistema deve validar os campos obrigatórios.
- O paciente deve ficar vinculado ao nutricionista responsável.

### HU-NUT-04 — Consultar pacientes
**Como** nutricionista,  
**quero** visualizar e pesquisar meus pacientes,  
**para** encontrar rapidamente quem preciso atender.

**Critérios de aceitação:**
- O sistema deve apresentar a lista de pacientes vinculados.
- O nutricionista deve conseguir pesquisar pacientes.
- As informações devem ser apresentadas de forma organizada.

### HU-NUT-05 — Visualizar informações do paciente
**Como** nutricionista,  
**quero** visualizar as informações de um paciente,  
**para** conhecer seu histórico e situação atual durante o atendimento.

**Critérios de aceitação:**
- O sistema deve apresentar os dados cadastrados do paciente.
- O nutricionista deve conseguir acessar as informações nutricionais disponíveis.
- O acesso deve respeitar as permissões do nutricionista.

### HU-NUT-06 — Registrar consulta
**Como** nutricionista,  
**quero** registrar uma consulta,  
**para** manter documentado o acompanhamento realizado.

**Critérios de aceitação:**
- O nutricionista deve conseguir informar a data da consulta.
- O nutricionista deve conseguir registrar observações.
- O registro deve ficar associado ao paciente correto.

### HU-NUT-07 — Consultar histórico de consultas
**Como** nutricionista,  
**quero** consultar o histórico de consultas de um paciente,  
**para** acompanhar os atendimentos anteriores.

**Critérios de aceitação:**
- O sistema deve apresentar as consultas registradas.
- As consultas devem apresentar suas respectivas datas.
- O nutricionista deve conseguir visualizar as informações registradas em cada consulta.

### HU-NUT-08 — Registrar avaliação nutricional
**Como** nutricionista,  
**quero** registrar uma avaliação nutricional,  
**para** acompanhar as condições e medidas do paciente.

**Critérios de aceitação:**
- O nutricionista deve conseguir registrar os dados disponíveis da avaliação.
- O sistema deve validar valores quando necessário.
- A avaliação deve ficar associada ao paciente e à data correspondente.

### HU-NUT-09 — Acompanhar evolução do paciente
**Como** nutricionista,  
**quero** acompanhar a evolução das informações nutricionais do paciente,  
**para** observar suas mudanças ao longo do acompanhamento.

**Critérios de aceitação:**
- O sistema deve permitir consultar avaliações anteriores.
- Os dados devem estar organizados cronologicamente.
- O nutricionista deve conseguir comparar informações de diferentes momentos.

### HU-NUT-10 — Criar plano alimentar
**Como** nutricionista,  
**quero** criar um plano alimentar personalizado,  
**para** orientar a alimentação do paciente de acordo com seu acompanhamento.

**Critérios de aceitação:**
- O nutricionista deve conseguir criar um novo plano para um paciente.
- O plano deve permitir inserir as informações necessárias.
- O plano deve ficar associado ao paciente correto.

### HU-NUT-11 — Editar plano alimentar
**Como** nutricionista,  
**quero** editar um plano alimentar,  
**para** atualizar as orientações conforme a evolução do paciente.

**Critérios de aceitação:**
- O nutricionista deve conseguir selecionar um plano existente.
- O sistema deve permitir alterar as informações autorizadas.
- As alterações devem ser salvas corretamente.

### HU-NUT-12 — Consultar planos alimentares
**Como** nutricionista,  
**quero** visualizar os planos alimentares de um paciente,  
**para** consultar suas orientações atuais e anteriores.

**Critérios de aceitação:**
- O sistema deve apresentar os planos associados ao paciente.
- O nutricionista deve conseguir visualizar o conteúdo dos planos.
- Os planos devem permitir diferenciação entre registros atuais e anteriores.

### HU-NUT-13 — Registrar observações do acompanhamento
**Como** nutricionista,  
**quero** registrar observações sobre o paciente,  
**para** manter informações importantes documentadas durante o acompanhamento.

**Critérios de aceitação:**
- O nutricionista deve conseguir adicionar observações.
- As observações devem ficar associadas ao paciente.
- O sistema deve registrar a data do registro.

### HU-NUT-14 — Consultar histórico completo do paciente
**Como** nutricionista,  
**quero** acessar o histórico de acompanhamento do paciente,  
**para** ter uma visão organizada de sua trajetória no sistema.

**Critérios de aceitação:**
- O histórico deve reunir os registros disponíveis do paciente.
- Os registros devem estar organizados cronologicamente.
- O acesso deve ser restrito ao nutricionista autorizado.
