# Histórico do usuário Aptus

Este relatório é gerado a partir da aplicação. Use o botão **Imprimir / Salvar PDF** para exportar o histórico completo com fotos, dados de evolução, refeições, compras, exercícios, atitudes e conquistas.

Para slides de apresentação, copie as seções coloridas para o PowerPoint e ajuste a escala. O conteúdo é preservado em português brasileiro.
